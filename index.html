BMS 難易度表ブリッジ

公開された Google スプレッドシートを BMS 難易度表として読める形に変換します。 データはどこにも保存せず、リクエストのたびにスプレッドシートから取得します。

シート一覧:

—

1 つのスプレッドシートに複数の難易度表を置けます。 beatoraja に登録する URL は、一覧ページで表を選ぶと表示されます。

シート一覧を開く

スプレッドシートの条件

  • 共有設定を「リンクを知っている全員が閲覧可」にする
  • md5 か sha256 の列を持つシートがデータとして読まれる （level と title も必須）
  • name / symbol / level_order / description を 1 行で持つシートがあれば、それがヘッダとして読まれる
  • level に symbol を含めない（★12 は ★★12 になる）

詳細は README を参照してください。
